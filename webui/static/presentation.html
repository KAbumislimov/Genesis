System Overview

What it is, how it works, what powers it

  • 🖥️ Web interface — Flask (Python) running in Docker on a Debian Linux server
  • 📡 Thin clients — Raspberry Pi / mini-PCs with mpg123, VLC, cron, SSH
  • 🔒 Security — HTTPS, session auth, role-based access, secrets vault
  • 📦 GitHub — full disaster recovery: restore everything in minutes
  • 🤖 Telegram bot — live notifications + remote control buttons
  • 📊 Monitoring — Grafana + Prometheus + Loki + node-exporter
  • 🎵 Audio — real-time playback control via SSH + mpg123/VLC on clients

Login & Security

Animated puzzle login, role-based access, auto-logout

  • 🎭 Animated login page — logos and form assemble from puzzle pieces on load
  • 👤 User roles — Admin (full access) vs Viewer (read-only, limited controls)
  • ⏱️ Auto-logout — all users are automatically logged out after 5 min of inactivity
  • 🔑 Remember Me — optional persistent session across browser restarts
  • 🛡️ HTTPS only — all traffic encrypted with TLS certificate
  • 📜 Full audit log — every action by every user is logged with timestamp
  • 🔒 Password-protected music library — songs sorted in folders, access controlled

Вход и безопасность

Анимированный пазл-вход, роли, автовыход

  • 🎭 Анимированная страница входа — логотипы и форма складываются из пазлов при загрузке
  • 👤 Роли пользователей — Админ (полный доступ) vs Зритель (только чтение, ограниченные кнопки)
  • ⏱️ Автовыход — все пользователи автоматически выходят после 5 мин бездействия
  • 🔑 Запомнить меня — опциональная постоянная сессия
  • 🛡️ Только HTTPS — весь трафик шифруется TLS-сертификатом
  • 📜 Полный журнал аудита — каждое действие каждого пользователя логируется с меткой времени
  • 🔒 Защищённая музыкальная библиотека — песни в папках, доступ контролируется
