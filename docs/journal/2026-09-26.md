## Модуль «Задачи» вместо Vikunja
Vikunja (отдельный контейнер, порт 8096) не подошла: нет поля «от кого/что просят» (только Название+Описание),
и не шлёт уведомление на закрытие задачи вообще (проверено напрямую — API, подписка на проект не помогает, есть только
`task.updated` вебхук без предиката «стало done»). По просьбе пользователя перенесли нужное в основную панель:
- Новые таблицы `tasks`, `task_comments` в `webui.db` (`webui/app.py`).
- Привилегии `tasks_view`/`tasks_manage` (категория «Задачи и заявки»); по умолчанию `tasks_view` есть у user/staff/helpdesk/eventmanager,
  `tasks_manage` (назначать/менять/удалять чужие) — у staff/helpdesk.
- Страницы `/tasks` (список, фильтры Активные/Мои/Завершённые/Все) и `/tasks/<id>` (описание, комментарии, статус, назначение),
  пункт «Задачи» в меню (`_v3_chrome.html`).
- Уведомления — через уже существующий `tg_notify()` (тот же канал, что у бэкапов/входов, общий чат): при создании задачи
  и при её завершении. Настройка `tg_notify_tasks` в Settings → Telegram, по умолчанию включена.
- Проверено на копии БД с подменой `tg_notify` (`scripts/tests/tasks_check.py`) — права, уведомления, статус, нельзя
  редактировать/удалить чужую задачу без `tasks_manage`. Визуально — Playwright, 1440 и 390px, без горизонтального скролла.
- Контейнер Vikunja (`~/projects/vikunja`) оставлен работать как есть — не трогали, пользователь решит сам, оставлять ли его.
