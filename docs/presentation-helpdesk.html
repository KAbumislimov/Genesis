Поиск и нумерация
Каждому тикету присваивается номер — можно найти в любой момент. Закрытые тикеты не пропадают, остаются в истории.
Публичные ссылки на тикет
Открытая ссылка без кода или защищённая PIN-кодом — выбирает тот, кто создаёт.
Роли и доступ
Каждый видит только то, что положено его роли
Team Lead
Все тикеты, панель управления, журнал действий (под PIN), применение темы для всех пользователей.
Helpdesk (tech)
Тикеты, назначенные на себя, ежедневные отчёты, учёт выданных активов.
Staff
Только создание заявки и отслеживание своих обращений.
Guest
Для внешних людей вроде директоров кампусов — упрощённая форма, видят только своё.
У каждого свой личный логин — общего admin-входа нет

⚠️ media-helpdesk — забытый старый прототип

Самая первая попытка до перехода на Helpdesk Ops — хоть и не использовалась, 6 дней подряд работала в открытом доступе в сети кампуса с логином, зашитым прямо в код.

admin / media2026 → контейнер остановлен
AUDIT_PIN = 1108 → новый случайный 8-значный + лимит попыток
слабые дефолты секретов в коде → сервер отказывается стартовать без реального секрета
Сеть и защита в браузере
Каждый ответ идёт с жёсткими заголовками
HTTP response headers
X-Frame-Options: DENY // нельзя встроить в чужую страницу
Strict-Transport-Security: max-age=31536000 // только HTTPS, навсегда
Content-Security-Policy: default-src 'self'... // чужой скрипт не загрузится
X-Content-Type-Options: nosniff
Один и тот же набор в обоих приложениях: Helpdesk Ops и campus-webui
