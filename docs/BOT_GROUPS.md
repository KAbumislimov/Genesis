# Боты и группы — как избежать дублирования

## Проблема
При одном голосовом сообщении бот отправляет 3 сообщения:
1. «Голос/аудио/МРЗ в чат от @user»
2. «Воспроизведение из чата»
3. «Из чата: голос/аудио от @user»

Если в **одной группе** добавлены оба бота (Narimanov и Genclik), получается **6 сообщений**.

## Решение
**В каждой группе должен быть только один бот.**

| Бот | Клиент | Группа |
|-----|--------|--------|
| **tg-campus-narimanov** | nctk (10.20.0.41) | Группа Нариманова |
| **tg-campus-genclik** | vm1 (10.70.0.41) | Группа Genclik |

### Что сделать
1. Откройте группу **Нариманова** (nctk) → Удалите бота Genclik из участников.
2. Откройте группу **Genclik** (vm1) → Удалите бота Narimanov из участников.

Или наоборот — оставьте в каждой группе того бота, который должен там работать.

### Проверка
В Telegram: Настройки группы → Участники. В каждой группе должен быть только один campus-бот.
